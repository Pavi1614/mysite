My First Project: HTTP to HTTPS

This is my first project where I converted a normal HTTP website into a secure HTTPS website.

I used Let's Encrypt to get a real SSL certificate for my domain pavitest.duckdns.org.

HTTPS encrypts data between the browser and my Kali server, so passwords and data cannot be stolen.

I hosted this site on my own Kali Linux server using Python, and made it public with Cloudflare Tunnel.
